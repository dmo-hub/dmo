GGoal

แก้ mobile ที่พังจริง (viewport + nav ล้นจอ), จัด IA ใหม่ ให้ nav ทุกหน้าตรงกันและหมวดหมู่ชัด (Feed / Tool / Item DB), sync ตัวเลข stat ที่ drift ระหว่าง index กับหน้าจริง, และเพิ่ม Cross-server Lookup — ค้นชื่อไอเทม/ซีล/ดิจิมอน EN·KR·TH หน้าเดียว alias-aware แทนการ hand-craft หน้า lookup ทีละ patch (แบบ seal-lookup-89).

AAudit findings (ตรวจจากไฟล์จริง + เปิด browser จริง)

P0 viewport meta หาย 5 หน้าหลัก — index, decks, digimon, seals, seal-lookup-89 → มือถือจริง render กว้าง ~980px ตัวหนังสือจิ๋ว (อีก 9 ไฟล์มีครบ — หลุดเฉพาะหน้าเก่า/หน้า generate)
P0 nav ล้นจอ mobile — screenshot 375px: เมนู "Breakth..." โดนตัด + ทั้งหน้ามี horizontal scroll. site.css มี media query แค่ 2 จุดทั้งไฟล์
P0 nav drift 12 สำเนา — แต่ละหน้าเมนูไม่เท่ากัน: index มี 7 ลิงก์, digimon มี 4, nametag มี 5, ไม่มีหน้าไหนลิงก์ Accessories เลย
P1 orphan 3 หน้า — accessories.html (57KB ทำเสร็จแล้ว!), seal-patch-th-88.html, seal-deal-calculator.html ไม่มีลิงก์เข้าจากหน้าใดเลย
P1 หมวดหมู่ปน — nav เอา Feed (Decks/Digimon/Seal), Tool (Breakthrough/Seal Lookup), Item DB (Name Tag/Accessories) มาเรียงแบน ๆ; seal-lookup-89 เป็นหน้า one-off ผูก patch #89 แต่อยู่ global nav → จะ rot ตอน #90 ออก
P1 stat drift — index บอก Seal 56 โพสต์ / หน้า seals จริงบอก 53; index บอก deck 21/35 / หน้า decks จริง 20/34 (เลข seal hardcode ใน build_index_html.py)
P1 Recent activity stale — จบที่ May 2026 ทั้งที่มีความเคลื่อนไหว seal มิ.ย.–ก.ค. 2026 (feed รวมแค่ decks+digimon ไม่รวม seal)
P2 ค้นหา cross-server ไม่มี — ข้อมูล mapping มีครบใน repo (kr_seal_en.json, th_seal_en.json, digimon_aliases.json, seal_data.json) แต่ user ค้นไม่ได้ ต้องรอ hand-craft หน้า lookup ทีละ patch
P2 SEO/share เป็นศูนย์ — ไม่มี meta description / OG tags / favicon สักหน้า; font โหลดผ่าน @import ใน CSS (render-blocking chain)
note รูป 34MB รวม ใน docs/img/ — decks.html ไม่มี loading="lazy" เลย (digimon.html มีแล้ว 19 จุด)

BBuild steps

1Phase 0 — Mobile fix (viewport + responsive nav)
  • เติม <meta viewport> ใน 5 หน้าที่หาย และ ใน template ของ build_index_html.py + build_digimon_html.py (ไม่งั้นโดน overwrite รอบ build หน้า)
  • site.css: mobile ≤720px → nav เลื่อนแนวนอนได้ (overflow-x:auto ไม่ wrap, ซ่อน scrollbar), ซ่อน .nav-meta, ลด hero padding/font, กัน horizontal overflow ทั้ง body
2Phase 1 — IA / จัดหมวดหมู่ + sync nav
  • Canonical nav ชุดเดียวทุกหน้า: Home · Decks · Digimon · Seal · Items · Tools — "Items" = Name Tag + Accessories (2 ลิงก์แยก หรือ dropdown), "Tools" = Breakthrough + Lookup ใหม่. ← ยืนยันชุดสุดท้ายตอน confirm
  • ถอด seal-lookup-89 ออกจาก global nav → ไปเป็น card "Related" บนหน้า seals พร้อม seal-patch-th-88 + seal-deal-calculator (เลิก orphan)
  • เพิ่ม Accessories card ใน index feature grid
  • แก้ nav ทั้งใน 10 ไฟล์ static + 2 builder templates ให้ตรงกัน
3Phase 1.5 — Content sync (stat + feed)
  • build_index_html.py: อ่านจำนวน seal posts จริงจาก docs/seal_data.json แทน hardcode 56 → เลขตรงกับหน้า seals เสมอ
  • Recent activity: ดึง seal posts ล่าสุด (จาก seal_data.json) รวมเข้า timeline → feed ไม่ stale
  • รัน builder → index.html ใหม่ → เลขตรงทุกหน้า
4Phase 2 — Cross-server Lookup (หน้าใหม่ lookup.html — ตอบโจทย์ความละเอียด/แม่นยำการค้นข้อมูลแต่ละเซิร์ฟ)
  • Builder ใหม่ builders/build_search_index.py → gen docs/search_index.json จาก: seal_data.json (ตาราง seal ทุกเซิร์ฟ) + kr_seal_en.json + th_seal_en.json + digimon_aliases.json + scan_result_digimon.json — ทุก entry เก็บ: ชื่อ EN/KR/TH, เซิร์ฟที่พบ, โพสต์ที่มา (URL+วันที่), rate/qty ถ้ามี, normalized key (ผ่าน logic เดียวกับ aliases.py norm() — precompute ฝั่ง Python เพื่อความแม่นยำ ไม่ port ไป JS)
  • หน้า docs/lookup.html (mockup-first ตาม convention repo): ช่องค้นหาเดียว พิมพ์ EN/KR/TH ได้หมด → ผลลัพธ์เป็น card สไตล์ seal-lookup-89: badge NA พบ / KR พบ / TH ไม่พบ + ลิงก์โพสต์ต้นทาง + วันที่ sweep ล่าสุด ("ไม่พบ" บอกขอบเขต sweep ไม่ใช่แค่เงียบ — ความแม่นยำอยู่ตรง provenance นี้)
  • Alias-aware: ค้น "Anomalocarimon" เจอ "Scorpiomon", ค้นชื่อไทยเจอสะกด KR/NA ผ่าน th_seal_en mapping
  • seal-lookup-89 ยังอยู่เป็น snapshot — หน้าใหม่ทำให้ patch ต่อไปไม่ต้อง hand-craft อีก
5Phase 3 — Meta + perf polish
  • meta description + OG title/description + favicon (SVG inline emoji) ทุกหน้า + templates
  • ย้าย font Prompt จาก @import ใน CSS → <link rel="preconnect">+stylesheet ใน head (ตัด render-blocking chain)
  • เติม loading="lazy" รูปทั้งหมดใน decks.html

RRisks / constraints

• index.html + digimon.html เป็นไฟล์ generate — ห้ามแก้ HTML ตรง ต้องแก้ที่ builder แล้ว re-run (seals.html แก้ head ตรงได้ — builder inject เฉพาะส่วนตาราง). decks.html hand-curated แก้ตรงได้.

• validate.py idempotency — หลังแก้ builder ต้องรัน builder + validate ให้ผ่าน (re-run แล้ว git diff ต้องว่าง)

• ตาม repo convention: ไม่ inline CSS ใหม่ — responsive rules ลง site.css เท่านั้น; หน้า lookup ใช้ mockup-first

• Out of scope: แปลงรูป 34MB เป็น WebP (เสนอทีหลังได้), ตัดสินใจ unhide Seal Deal, redesign theme
